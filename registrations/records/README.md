# Execution and Results Records

This directory contains the completed-run execution records and empirical result summaries for the experimental batches reported in the paper:
**"agent-risk: Risk Assessment for Changes to AI Agents"** (arXiv).

These records document the executed episode counts, observed harm frequencies, confidence envelopes (Newcombe paired hybrid score intervals, Clopper-Pearson exact binomial bounds), execution timings, system health metrics (disk watchdog logs, serving state), and deviations (if any) as captured at run completion.

Like the pre-registration files in the parent directory (`registrations/`), all documents here have been sanitized for public release by replacing internal VM hostnames, cloud IP addresses, allocation codes, and filesystem UUIDs with neutral placeholders (`<HOST_1>`, `<HOST_2>`, `<IP_A>`, `<IP_B>`, `<ALLOCATION_1>`, etc.) while preserving all numbers, sample sizes, margins, thresholds, hashes, and timestamps verbatim.
